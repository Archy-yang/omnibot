Goroutine 是 Go 语言中轻量级的并发执行单元，由 Go 运行时管理，比操作系统线程更高效。每个 goroutine 初始栈只有几 KB，可按需动态增长。

Channel 是 goroutine 之间的通信管道，遵循 "不要通过共享内存来通信，而应通过通信来共享内存" 的设计哲学。

go 
func main() {
    ch := make(chan string, 1)

    go func() {
        ch <- "Hello from goroutine!"
    }()

    msg := <-ch
    fmt.Println(msg)
}

在这个示例中，子 goroutine 通过 channel 发送消息，主 goroutine 接收消息，实现了安全的并发通信。
