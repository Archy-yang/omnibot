这是一个 Go HTTP 日志中间件，可以记录请求方法、路径、状态码和响应耗时：

Go
func LoggingMiddleware(next http.Handler) http.Handler { return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) { start := time.Now() wrapped := &responseWriter{ResponseWriter: w, statusCode: 200} next.ServeHTTP(wrapped, r) log.Printf("[%s] %s %d %v", r.Method, r.URL.Path, wrapped.statusCode, time.Since(start)) }) }
  • 记录请求方法、路径、Content-Type
  • 捕获响应状态码
  • 计算请求处理耗时
