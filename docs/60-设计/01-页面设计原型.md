# OmniBot 前端页面设计原型

> 版本：v1.10.0 | 基于实际代码分析 | 2026-06-28

---

## 一、页面总览

OmniBot 前端采用经典的**双栏布局**：左侧可折叠侧边栏 + 右侧主内容区。

- **侧边栏**：包含 Logo、导航菜单、历史会话列表和用户信息区。支持展开（260px）和折叠（52px Rail 模式）两种状态。
- **主内容区**：包含顶栏、消息展示区和底部输入区。消息区居中限宽，输入区固定在底部。

整体风格简洁、轻量，以白色为底色，绿色 `#10a37f` 为强调色，强调内容可读性和交互反馈。

## 三、组件设计规范

### 3.1 侧边栏（Sidebar）

| 属性 | 值 |
|------|-----|
| 展开宽度 | 260px |
| 折叠宽度 | 52px（Rail 模式） |
| 背景色 | `#f9f9f9` |
| 过渡动画 | 200ms ease |

**结构分区：**

1. **顶部区域**
   - Logo 按钮：绿色圆形 SVG，填充色 `#10a37f`，尺寸约 28px
   - 折叠/展开按钮：紧邻 Logo，图标 20px，点击切换 Rail 模式

2. **菜单区**
   - 5 个菜单项：新聊天、搜索聊天、图片、应用、设置
   - 图标尺寸：20px
   - 文字字号：14px
   - 整行圆角：8px
   - 悬停背景色变化（150ms 过渡）
   - 折叠态仅显示图标，hover 展示 Tooltip 文字

3. **历史列表区**
   - 标题 "你的聊天"：12px，颜色 `#8e8ea0`，字重 500
   - 会话列表项：14px 字号，单行文本截断（`overflow: hidden; text-overflow: ellipsis; white-space: nowrap`）
   - 当前选中项有高亮背景
   - 可滚动，溢出隐藏

4. **底部用户信息区**
   - 圆形头像（尺寸约 28-36px）
   - 用户名 + 版本号文字（14px）
   - 贴底固定

### 3.4 聊天消息（ChatMessage）

**用户消息：**

| 属性 | 值 |
|------|-----|
| 对齐 | 右对齐 |
| 气泡背景 | `#f4f4f4` |
| 气泡圆角 | 22px |
| 最大宽度 | 75% |
| 文字字号 | 15px |
| 文字颜色 | `#0d0d0d` |
| 行高 | 1.6 / 1.75 |

**助手消息：**

| 属性 | 值 |
|------|-----|
| 头像 | 32px 圆形，蓝色渐变 `#2080f0` → `#4dabff` |
| 名称 | "OmniBot"，字号 15px，字重 600 |
| 内容缩进 | 42px（与头像右侧对齐） |
| 文字字号 | 15px，颜色 `#0d0d0d` |
| Markdown 渲染 | 使用 marked + DOMPurify |

**助手消息特殊元素：**

- **工具思考段**：可展开/折叠的条形区域，标题栏显示工具名称和状态图标（如 "正在调用 RSS Reader..."），展开后显示详细内容。字号 13px，颜色 `#6b7280`，行高 1.5
- **操作栏**：hover 消息行时显示，包含复制按钮等操作
- **打字指示器**：三个灰色圆点（`#a0a0a0`）跳动动画，循环周期 1400ms，缓动 ease-in-out
