# 40-踩坑记录

本目录存放技术问题复盘、解决方案，目的是避免团队重复踩坑。

## 记录模板

每个问题记录应包含：

```markdown
## 问题标题

**发生时间**：YYYY-MM-DD
**影响范围**：xxx 模块 / 全系统
**严重程度**：P0 故障 / P1 阻塞 / P2 一般问题

### 问题描述
...

### 问题根因
...

### 解决方案
...

### 经验教训
...

### 后续行动
- [ ] xxx
- [ ] xxx
```

## 分类建议

按问题类型建文件：
- `依赖问题.md` - Go module、第三方依赖
- `环境问题.md` - 本地开发、CI/CD、线上环境
- `第三方集成.md` - 微信、LLM、Redis 等集成
- `性能问题.md` - 性能瓶颈、优化记录
- `数据问题.md` - 数据库迁移、数据一致性
