## 风险跟踪

| 风险 | 等级 | 应对措施 |
|------|------|----------|
| 加密密钥泄露 | 高 | 密钥通过环境变量配置，不提交代码 |
| 用户配置滥用 | 中 | 每分钟限流 60 次，配置操作 5 次限流 |
| 错误提示不友好 | 低 | 按错误码分类提示，引导重新配置 |
