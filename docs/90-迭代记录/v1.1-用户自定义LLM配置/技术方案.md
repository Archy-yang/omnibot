## 二、整体架构

### 2.1 调用链设计

```
用户消息
    ↓
Wechat Handler
    ↓
UserLLMConfigService 获取用户配置
    ↓   ↓   ↓   ↓   ↓
┌─────────────────────────────────┐
│ 配置存在且有效？                 │
├───────────────┬─────────────────┤
│    是         │      否         │
└───────────────┴─────────────────┘
    ↓              ↓
用用户配置调用    用系统默认配置
LLM 客户端工厂   调用 LLM
    ↓              ↓
    └──────────────┘
            ↓
    返回回复给用户
```

### 2.2 配置 Fallback 规则

```
用户配置优先级：
1. 用户自定义 API Key（必填）
2. 用户自定义 API 地址（可选，默认 OpenAI 官方）
3. 用户自定义模型名（可选，默认 gpt-3.5-turbo）

配置有效判断：
- API Key 非空 → 认为用户要使用自定义配置
- 调用失败 → 直接返回错误提示，不 fallback 到系统配置（避免混淆）
```

## 三、数据模型设计

### 3.1 数据库表：user_llm_configs

| 字段名 | 类型 | 说明 | 约束 |
|--------|------|------|------|
| id | bigint | 主键 | PRIMARY KEY AUTO_INCREMENT |
| user_id | bigint | 用户 ID | UNIQUE NOT NULL, FOREIGN KEY → users.id |
| api_key | varchar(512) | 加密后的 API Key | NOT NULL |
| base_url | varchar(256) | API 地址 | NULLABLE |
| model | varchar(128) | 默认模型名 | NULLABLE, DEFAULT 'gpt-3.5-turbo' |
| status | tinyint | 状态：0-正常, 1-禁用 | NOT NULL DEFAULT 0 |
| created_at | datetime | 创建时间 | NOT NULL |
| updated_at | datetime | 更新时间 | NOT NULL |

**设计说明：**
- `user_id` 唯一约束：一个用户只能有一套配置
- `api_key` 长度 512：AES 加密后会膨胀，预留足够空间
- `status` 字段：预留管理员禁用功能

### 3.2 Domain 层实体

**文件：`internal/domain/user/llm_config.go`**

```go
type LLMConfig struct {
    ID        int64
    UserID    int64
    APIKey    string  // 加密后存储
    BaseURL   *string // nil 表示用默认
    Model     *string // nil 表示用默认
    Status    int8    // 0-正常, 1-禁用
    CreatedAt time.Time
    UpdatedAt time.Time
}

// 配置状态常量
const (
    LLMConfigStatusNormal   = int8(0)
    LLMConfigStatusDisabled = int8(1)
)

// IsEnabled 配置是否启用
func (c *LLMConfig) IsEnabled() bool {
    return c.Status == LLMConfigStatusNormal && c.APIKey != ""
}

// GetBaseURL 获取实际使用的 API 地址
func (c *LLMConfig) GetBaseURL() string {
    if c.BaseURL == nil || *c.BaseURL == "" {
        return "https://api.openai.com/v1"
    }
    return *c.BaseURL
}

// GetModel 获取实际使用的模型
func (c *LLMConfig) GetModel() string {
    if c.Model == nil || *c.Model == "" {
        return "gpt-3.5-turbo"
    }
    return *c.Model
}
```

## 四、模块设计

### 4.1 加密工具模块

**文件：`internal/pkg/crypto/aes.go`**

**功能：**
- AES 加密 API Key
- AES 解密 API Key
- 加密密钥从环境变量读取（`LLM_CONFIG_ENCRYPT_KEY`）

**接口定义：**
```go
// Encrypt 加密
func Encrypt(plaintext string) (string, error)

// Decrypt 解密
func Decrypt(ciphertext string) (string, error)
```

**安全设计：**
- 密钥 32 字节（AES-256）
- 使用 GCM 模式，带随机 nonce
- 加密结果格式：`base64(nonce + ciphertext)`

### 4.3 Service 层

**文件：`internal/service/user/llm_config_service.go`**

**接口定义：**
```go
type LLMConfigService interface {
    // GetConfigForUser 获取用户用于 LLM 调用的配置
    // 返回: (apiKey, baseURL, model, hasCustomConfig, error)
    GetConfigForUser(userID int64) (string, string, string, bool, error)
    
    // SetAPIKey 设置用户 API Key
    SetAPIKey(userID int64, apiKey string) error
    
    // SetBaseURL 设置用户 API 地址
    SetBaseURL(userID int64, baseURL string) error
    
    // SetModel 设置用户默认模型
    SetModel(userID int64, model string) error
    
    // GetConfigView 获取用户配置视图（用于展示，Key 脱敏）
    GetConfigView(userID int64) (*LLMConfigView, error)
    
    // ClearConfig 清除用户配置
    ClearConfig(userID int64) error
}

// LLMConfigView 配置视图，用于前端展示
type LLMConfigView struct {
    HasConfig    bool   // 是否有配置
    APIKeyMasked string // 脱敏后的 Key: sk-ab...fg
    BaseURL      string // API 地址
    Model        string // 模型名
    StatusText   string // 状态描述: "使用你的自定义配置" / "使用系统默认"
}
```

**业务逻辑：**
1. `GetConfigForUser`：查询配置 → 解密 API Key → 返回供 LLM 客户端使用
2. `SetAPIKey`：加密后存储，不存在则创建，存在则更新
3. `GetConfigView`：Key 只显示前后 3 位，中间用 `...` 代替

### 4.4 Wechat Handler 集成

**文件：`internal/api/wechat/handler.go`**

**修改点：**

1. **Handler 结构体增加依赖：**
```go
type Handler struct {
    config         Config
    llmClient      LLMClient
    llmConfigService user.LLMConfigService // 新增
    userService    UserService
}
```

2. **HandleMessage 中注入用户配置：**
```go
// 在调用 LLM 前获取用户配置
apiKey, baseURL, model, hasCustom, err := h.llmConfigService.GetConfigForUser(userID)
if err != nil {
    // 记录错误，fallback 到系统默认
    logger.Warn("failed to get user llm config", zap.Error(err))
}

var resp string
if hasCustom {
    // 使用用户自定义配置调用
    customClient := llm.NewOpenAIClientWithConfig(apiKey, baseURL, model)
    resp, err = customClient.ChatCompletion(...)
} else {
    // 使用系统默认
    resp, err = h.llmClient.ChatCompletion(...)
}
```

3. **新增命令处理器：**
```go
// 识别并处理配置命令
func (h *Handler) handleConfigCommand(msg *WechatMessage) (string, bool) {
    content := strings.TrimSpace(msg.Content)
    
    switch {
    case content == "#模型设置":
        return h.renderConfigMenu(), true
    case strings.HasPrefix(content, "#设置Key "):
        return h.handleSetAPIKey(msg.FromUserName, content), true
    case strings.HasPrefix(content, "#设置地址 "):
        return h.handleSetBaseURL(msg.FromUserName, content), true
    case content == "#我的配置":
        return h.handleGetConfig(msg.FromUserName), true
    case content == "#重置模型":
        return h.handleClearConfig(msg.FromUserName), true
    }
    
    return "", false
}
```

4. **错误处理增强：**
```go
// 自定义配置调用失败时的友好提示
func (h *Handler) formatLLMError(err error) string {
    if strings.Contains(err.Error(), "401") {
        return "❌ API Key 无效，请发送「#模型设置」重新配置"
    }
    if strings.Contains(err.Error(), "timeout") || strings.Contains(err.Error(), "connection refused") {
        return "❌ 模型服务访问失败，请检查 API 地址配置"
    }
    if strings.Contains(err.Error(), "429") {
        return "❌ 调用次数已达上限，请稍后再试"
    }
    return "❌ 模型调用失败，请稍后重试或检查配置"
}
```

## 五、安全设计

### 5.1 数据加密

| 项 | 方案 |
|----|------|
| 加密算法 | AES-256-GCM |
| 密钥存储 | 环境变量 `LLM_CONFIG_ENCRYPT_KEY`，不提交代码 |
| 密钥长度 | 32 字节（256位） |
| 加密范围 | 仅 `api_key` 字段加密，base_url/model 明文 |

### 5.2 输入验证

| 字段 | 验证规则 |
|------|----------|
| API Key | 必须以 `sk-` 开头，长度 30-200 字符 |
| API 地址 | 必须是合法的 HTTPS/HTTP URL |
| 模型名 | 长度不超过 128 字符，只允许字母、数字、横杠、点 |

### 5.3 限流保护

- 每个用户每分钟最多调用 60 次（防止滥用用户自己的 Key 消耗我们服务器资源）
- 配置设置操作每分钟最多 5 次（防止暴力尝试 Key）
