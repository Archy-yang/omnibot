## 跨模块依赖图

```
接入层 → 服务层 → 仓储层 → 领域层 → 基础设施层
（微信、飞书等）    （数据持久化）   （纯模型）
```

### 依赖规则
1. 只能单向依赖，不能反向依赖
2. 上层只能依赖下层的**接口**，不能依赖具体实现
3. 领域层不能依赖任何其他层

---

## 新增模块 checklist

新增任何模块都需要回答以下问题：

1. 这个模块属于哪个领域？
2. 它的上游依赖是什么？
3. 它的下游依赖是什么？
4. 它暴露的接口是什么？
5. 它需要持久化的数据是什么？
6. 这个模块是可替换的吗？
7. 单元测试覆盖策略是什么？
