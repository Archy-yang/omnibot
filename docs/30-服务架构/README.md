# 30-服务架构

本目录存放技术架构设计、系统设计方案、模块设计文档。

## 目录结构

```
30-服务架构/
├── 00-系统设计总览.md      # 整体系统架构
├── modules/               # 模块设计文档
├── diagrams/              # 架构图、数据流图
├── internal/              # 按代码目录结构镜像的模块文档
│   ├── api/
│   ├── db/
│   ├── service/
│   ├── repository/
│   └── domain/
├── pkg/                   # 公共包文档
└── superpowers/           # superpowers 实现计划
```

## 架构文档要求

每个模块的架构文档应包含：
1. 模块职责
2. 入口函数
3. 处理流程
4. 已实现能力
5. 依赖关系
6. 配置说明

## 代码镜像原则

`internal/` 和 `pkg/` 目录结构与项目代码目录结构**完全一致**，确保：
- 代码文件 ↔ 架构文档一一对应
- 修改代码后必须同步更新架构文档
