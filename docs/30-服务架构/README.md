## 文档标准（v2.0 起强制执行）

所有新写的架构文档必须符合「三段式标准」：

1. ✅ 文档信息（版本、状态、最后更新时间）
2. ✅ 这个文档解决什么问题？
3. ✅ 读之前你需要知道什么？
4. ✅ 核心内容
5. ✅ 设计决策记录（ADR）
6. ✅ 下一步演进方向

不符合这个标准的旧文档会逐步重构迁移到新体系。
