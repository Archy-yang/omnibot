## 📋 每个文档的标准结构

所有架构文档都应该包含：

| 部分 | 说明 |
|------|------|
| 文档信息 | 适用版本、最后更新时间、状态 |
| 1. 这个文档解决什么问题？ | 一句话说明文档的目标 |
| 2. 读之前你需要知道什么？ | 前置依赖和背景知识 |
| 核心内容 | 设计细节、接口定义、数据结构 |
| 设计决策记录（ADR） | 为什么这么设计？有什么备选方案？ |
| 下一步演进 | 未来可能的变化方向 |
