- [01-高层设计/](../01-高层设计/) - 整体架构
- [02-模块设计/](../02-模块设计/) - 按领域分类的模块设计

## 目录说明

本目录结构与代码目录结构**完全镜像**，方便快速定位：

```
06-代码参考/
├── internal/              ← 对应代码根目录的 internal/
│   ├── api/              ← HTTP 接口层
│   ├── service/          ← 业务服务层
│   ├── repository/       ← 数据访问层
│   ├── domain/           ← 领域模型
│   ├── client/           ← 外部客户端
│   ├── db/               ← 数据库基础设施
│   └── middleware/       ← 中间件
│
└── pkg/                  ← 对应代码根目录的 pkg/
    ├── config/           ← 配置管理
    └── logger/           ← 日志模块
```

---

## 每个文档包含什么？

本目录的文档只需要包含：
1. 主要公开接口/函数的签名
2. 简单的参数说明
3. 返回值说明
4. 常见的调用示例

**不需要包含：**
- ❌ 设计思路（请去 02-模块设计 看）
- ❌ 架构决策理由（请去 02-模块设计 看 ADR）
- ❌ 未来演进计划（请去 01-高层设计 看路线图）
