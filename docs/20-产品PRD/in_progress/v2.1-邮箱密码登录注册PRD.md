## 二、需求背景与目标

### 2.1 背景

OmniBot 当前 Web 端用户是**匿名身份**:浏览器换了、缓存清了,历史对话和长期记忆
就再也找不回来。用户没有一个真正"属于自己"的账号。

这带来两个问题:

- 用户无法在不同设备 / 浏览器上访问同一份对话与记忆
- 没有稳定账号,就无法把"同一个人"在 Web、微信、飞书上的身份关联起来

v2.0 把「用户体系」列为核心方向。要让「单一长期对话」真正属于一个人,而不是属于
一个随时会丢的浏览器,必须先让用户拥有真实账号。

### 2.2 为什么是邮箱密码

- 产品定位已确认:**Web 是唯一的账号注册入口,对所有人开放**;微信、飞书只能
  绑定到已有账号,不能独立注册(详见 v2.2)
- 邮箱 + 密码是门槛最低、对用户最熟悉的自有账号方式,不依赖短信、不强制第三方账号

### 2.3 目标

> 让用户能用邮箱和密码在 Web 端注册、登录 OmniBot,拥有一个稳定的个人账号。
> 登录后,他的所有对话、长期记忆、模型配置都归属于这个账号,换设备登录也能延续。

## 三、产品范围

### 3.1 本期 v2.1 做什么

1. **注册**:用邮箱 + 密码创建账号
2. **登录**:用邮箱 + 密码登录,登录后保持登录状态
3. **登录态保持**:登录后刷新页面、重开浏览器,在有效期内无需重新登录
4. **登出**:用户可主动退出登录
5. **访问控制**:未登录用户访问对话主页时,引导其先登录
6. **身份归属**:登录后产生的对话、记忆、模型配置都归属当前账号

### 3.2 本期 v2.1 不做什么

1. ❌ 邮箱验证 / 激活邮件(注册后直接可用,邮箱真实性校验留后续)
2. ❌ 找回密码 / 重置密码(留后续)
3. ❌ 修改密码、修改邮箱(留后续)
4. ❌ 第三方账号登录(微信 / Google / GitHub)
5. ❌ 手机号登录
6. ❌ 飞书 / 微信账号绑定(那是 v2.2)
7. ❌ 历史匿名用户数据迁移(当前仅测试数据,直接清空重来)
8. ❌ 多设备登录管理、登录设备列表

### 3.3 与现有能力的关系

- 登录后,长期记忆、对话历史、模型配置等已有能力**照常工作**,只是从"归属匿名
  浏览器"变为"归属登录账号",这些功能本身的体验不变
- 微信、飞书入口的用户身份处理本期不受影响(飞书的账号归属调整在 v2.2 处理)

## 五、字段与规则约定

为避免理解歧义,本期所有邮箱、密码相关规则统一约定如下,功能描述与验收均以此为准。

### 5.1 邮箱规则

| 项 | 规则 |
|----|------|
| 格式 | 必须是合法邮箱格式(形如 `name@domain.com`),含且仅含一个 `@`,域名部分含 `.` |
| 大小写 | **不区分大小写**。`Foo@X.com` 与 `foo@x.com` 视为同一账号;系统统一按小写处理与比对 |
| 前后空格 | 自动去除首尾空格后再校验 |
| 长度 | 不超过 254 字符(邮箱通用上限) |
| 唯一性 | 同一邮箱(忽略大小写后)只能注册一个账号 |

### 5.2 密码规则

| 项 | 规则 |
|----|------|
| 长度 | **8 ~ 64 个字符**,不足 8 位或超过 64 位均拒绝 |
| 字符 | 不强制大小写 / 数字 / 符号组合,允许任意可见字符 |
| 空格 | 密码**不去除**首尾空格(空格是密码的一部分,原样使用) |
| 大小写 | 区分大小写 |

### 5.3 登录态规则

| 项 | 规则 |
|----|------|
| 有效期 | 登录后保持登录 **30 天** |
| 续期 | 本期不做自动续期;30 天到期后需重新登录 |
| 跨设备 | 同一账号可在多个设备 / 浏览器同时登录,互不影响 |
| 失效表现 | 登录态过期后,用户下一次操作被引导回登录页 |

## 六、功能描述

### 6.1 注册

**注册页字段**(共 3 个输入项):
- 邮箱
- 密码
- 确认密码(需与密码完全一致)

**提交后的校验顺序与提示**:

| 校验项 | 不通过时的提示 |
|--------|----------------|
| 邮箱不能为空且格式合法 | 「请输入有效的邮箱地址」 |
| 密码长度 8~64 位 | 「密码长度需为 8~64 位」 |
| 两次密码一致 | 「两次输入的密码不一致」 |
| 邮箱未被注册 | 「该邮箱已注册,请直接登录」 |

- 全部通过:创建账号 → **自动进入登录状态** → 跳转到对话主页(无需再手动登录)
- 任一不通过:停留在注册页,在对应输入项下方给出上述提示,已填内容不清空(密码框可清空)

### 6.2 登录

**登录页字段**:
- 邮箱
- 密码

**提交后的结果**:

| 情况 | 结果 |
|------|------|
| 邮箱密码正确,账号正常 | 进入登录状态,跳转对话主页 |
| 邮箱未注册 或 密码错误 | 提示「邮箱或密码错误」(**不区分**两者,防止探测邮箱是否注册) |
| 账号被封禁 / 已注销 | 提示「该账号不可用」 |
| 邮箱 / 密码为空 | 提示「请输入邮箱和密码」 |

### 6.3 登出

- 登录状态下,用户可在界面上找到「登出」入口并主动退出
- 登出后:清除本地登录态 → 跳转到登录页
- 登出仅影响当前设备 / 浏览器,不影响该账号在其他设备的登录态

### 6.4 访问控制

- **未登录**用户访问对话主页(`/`)或其他需要身份的页面时:**一律跳转到登录页**,
  不展示任何主页内容
- 登录页、注册页本身无需登录即可访问
- 已登录用户访问登录 / 注册页时:直接跳回对话主页(已登录无需再登录)

### 6.5 身份归属

- 用户登录后产生的所有对话消息、长期记忆、模型配置,都记录在其账号名下
- 同一账号在不同设备 / 浏览器登录,看到的是同一份对话历史、记忆和配置
- 不同账号之间数据完全隔离,互不可见

### 6.6 前端页面

- **登录页**:邮箱输入框、密码输入框、登录按钮、「还没有账号?去注册」入口
- **注册页**:邮箱输入框、密码输入框、确认密码输入框、注册按钮、「已有账号?去登录」入口
- 提交过程中按钮显示加载态并禁用,避免重复提交
- 视觉风格与 v2.0 设计保持一致(简洁,绿色主色 `#10a37f`)

## 七、交互流程

### 7.1 注册

```
进入注册页 → 填写邮箱 + 密码 + 确认密码 → 提交
   ├─ 邮箱为空/格式非法 → 提示「请输入有效的邮箱地址」,留在注册页
   ├─ 密码长度不在 8~64 位 → 提示「密码长度需为 8~64 位」,留在注册页
   ├─ 两次密码不一致 → 提示「两次输入的密码不一致」,留在注册页
   ├─ 邮箱已注册 → 提示「该邮箱已注册,请直接登录」,留在注册页
   └─ 全部通过 → 创建账号 → 自动登录 → 跳转对话主页
```

### 7.2 登录

```
进入登录页 → 填写邮箱 + 密码 → 提交
   ├─ 邮箱/密码为空 → 提示「请输入邮箱和密码」
   ├─ 邮箱未注册 或 密码错误 → 统一提示「邮箱或密码错误」
   ├─ 账号被封禁/注销 → 提示「该账号不可用」
   └─ 成功 → 进入登录态(保持 30 天)→ 跳转对话主页
```

### 7.3 访问与登出

```
未登录访问主页 → 一律跳转登录页(不展示主页内容)
已登录访问登录/注册页 → 跳回对话主页
登录态过期后操作 → 跳转登录页要求重新登录
点击登出 → 清除本地登录态 → 跳转登录页
```

## 八、非功能需求

### 8.1 安全

- 用户密码**加密存储**,系统任何地方都不保存、不输出明文密码
- 日志中不出现密码、不出现可用于冒充用户的完整登录凭证
- 登录失败提示不泄露"邮箱是否已注册",防止账号探测
- 对外错误提示不暴露系统内部细节

### 8.2 体验

- 注册 / 登录操作有即时反馈(加载中、成功、失败)
- 失败提示清晰、可理解,告诉用户下一步怎么做

### 8.3 可靠性

- 注册过程要么完整成功,要么完全不生效,不会产生"半个账号"
- 同一邮箱并发注册不会产生重复账号

## 九、验收标准

### 9.1 功能验收

- [ ] 新邮箱可注册成功,注册后自动登录并进入主页
- [ ] 重复邮箱注册被拒,提示「该邮箱已注册,请直接登录」
- [ ] 邮箱大小写不同(如 `Foo@X.com` / `foo@x.com`)视为同一账号,不能重复注册
- [ ] 密码少于 8 位或多于 64 位被拒,提示长度要求
- [ ] 两次密码不一致被拒
- [ ] 正确邮箱密码可登录成功
- [ ] 错误邮箱 / 密码登录失败,统一提示「邮箱或密码错误」
- [ ] 被封禁 / 注销账号无法登录,提示「该账号不可用」
- [ ] 登录后保持登录,30 天内刷新页面、重开浏览器仍登录
- [ ] 登录态过期后操作被跳转登录页
- [ ] 登出后回到登录页,不影响其他设备登录态
- [ ] 未登录访问主页一律跳登录页,不展示主页内容
- [ ] 已登录访问登录 / 注册页时跳回主页
- [ ] 登录后产生的对话 / 记忆 / 模型配置归属当前账号
- [ ] 同一账号换设备登录,能看到原有对话和记忆
- [ ] 不同账号间数据互不可见

### 9.2 安全验收

- [ ] 系统不保存密码明文
- [ ] 日志中无密码、无完整登录凭证
- [ ] 登录失败提示不区分"邮箱不存在"与"密码错误"

### 9.3 体验验收

- [ ] 注册 / 登录有加载与结果反馈
- [ ] 提交中按钮禁用,不能重复提交
- [ ] 各类失败都有清晰可懂的提示
