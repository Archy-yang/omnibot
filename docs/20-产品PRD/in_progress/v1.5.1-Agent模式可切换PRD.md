## 二、需求背景与目标
### 2.1 当前问题
1. **Agent LLM配置不兼容用户自定义**：当前Agent服务硬编码使用系统全局LLM配置，即使用户在设置页配置了自定义的LLM服务商、API Key、模型，Agent接口也不会使用，导致Agent功能无法正常使用（默认配置是测试无效地址）
2. **Agent模式强制启用不可切换**：当前所有对话默认走Agent接口，对于不需要工具能力的普通聊天场景，用户希望可以切换回普通模式，减少不必要的工具调用开销，响应更快
### 2.2 目标
1. 🔄 Agent接口与普通聊天接口**LLM配置逻辑完全对齐**，支持用户自定义LLM配置
2. 🎛️ 前端支持**Agent模式手动切换**，用户可以自由选择是否启用Agent能力

## 三、产品范围
### 3.1 本次 v1.5.1 做什么
#### 后端能力
1. Agent接口适配用户自定义LLM配置，优先级和普通聊天完全一致：
   - 优先使用当前用户配置的LLM（服务商、API Key、BaseURL、模型）
   - 用户无自定义配置时， fallback到系统默认配置
2. 完全复用现有LLM客户端工厂逻辑，不需要重复开发
#### 前端能力
1. 聊天输入框区域增加**Agent模式切换开关**：
   - 两种状态：「普通模式」（默认）、「Agent模式」
   - 开关状态本地持久化（存在localStorage），刷新页面不丢失
   - Agent模式开启时，输入框有明显视觉标识（如旁边显示「Agent」小标签）
2. 模式切换逻辑：
   - 切换不影响当前已有的对话上下文
   - 切换后下一条发送的消息生效，走对应接口
   - 普通模式走原来的 `/api/v1/chat/messages/stream` 接口
   - Agent模式走 `/api/v1/chat/messages/agent/stream` 接口
3. 兼容现有Agent功能：Agent模式下仍保留「查看思考过程」、工具调用展示等所有功能
### 3.2 本次 v1.5.1 不做什么
1. ❌ 不修改Agent核心推理/工具调用逻辑
2. ❌ 不新增任何工具能力
3. ❌ 不做多Agent类型选择（仅支持开关，后续版本再扩展多Agent选择）
4. ❌ 不做会话粒度的模式记忆（本次是全局开关，后续可考虑会话级独立设置）
5. ❌ 微信端不做适配（仅Web端支持）

## 四、功能详情
### 4.1 后端适配逻辑
1. Agent接口在接收到用户请求时，先查询当前用户的自定义LLM配置
2. 如果存在自定义配置，使用用户配置动态创建LLM客户端实例
3. 如果没有自定义配置，使用系统全局默认LLM客户端
4. 完全复用普通聊天接口的LLM配置查询、客户端创建逻辑，保持逻辑一致性
### 4.2 前端交互设计
1. **开关位置**：输入框右侧，发送按钮左边
2. **开关样式**：
   - 关闭状态：灰色，无标签，默认样式
   - 开启状态：蓝色，旁边显示「Agent」小标签，提示当前是Agent模式
3. **hover提示**：鼠标hover开关时显示tooltip：
   - 关闭时：「开启Agent模式，支持工具调用、多步推理」
   - 开启时：「关闭Agent模式，使用普通聊天，响应更快」
4. **模式切换反馈**：切换时显示toast提示：「已切换到普通模式」/「已切换到Agent模式」
### 4.3 降级逻辑
1. Agent接口不可用时，自动降级到普通模式，提示用户「Agent服务暂时不可用，已切换到普通模式」
2. 用户无自定义LLM配置时，Agent模式使用系统默认配置，不影响使用
---
## 五、非功能需求
1. **性能**：模式切换无感知，接口响应速度和原有模式一致
2. **兼容性**：兼容所有主流浏览器，移动端适配正常
3. **稳定性**：Agent配置适配不影响现有普通聊天功能，开关切换不会导致消息丢失
4. **数据安全**：LLM密钥仍然遵循原有加密存储逻辑，不会泄露
---
## 六、验收标准
### 后端验收
1. ✅ 用户配置了自定义LLM后，发送Agent消息，使用用户配置的LLM服务商/Key/模型
2. ✅ 用户无自定义配置时，Agent消息使用系统默认配置
3. ✅ 普通聊天接口功能不受任何影响
4. ✅ Agent原有功能（工具调用、多步推理、思考过程输出）完全正常
### 前端验收
1. ✅ 聊天页面输入框旁边显示Agent模式开关，默认关闭
2. ✅ 切换开关状态后，刷新页面状态保持不变
3. ✅ 关闭状态下发送消息走普通聊天接口，无思考过程展示
4. ✅ 开启状态下发送消息走Agent接口，有工具调用时显示思考过程
5. ✅ 切换开关时不影响当前已有的对话内容
6. ✅ 开启状态下输入框有明显的Agent模式标识
