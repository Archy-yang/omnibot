# 当前开发进度

## 需求背景
构建一个微信公众号智能对话客服系统，具备以下能力：
- 接收微信公众号用户消息
- 调用大模型进行对话生成
- 基于对话内容抽取和生成用户记忆
- 利用历史记忆提供个性化回复

## 当前已完成
- ✅ 项目初始化搭建
- ✅ 配置管理模块（基于 Viper）
- ✅ 日志管理模块（基于 Zap + Lumberjack）
- ✅ HTTP 服务器框架（Gin）
- ✅ 路由注册基础结构
- ✅ 微信回调接口框架
- ✅ 服务探活端点 `/ping`
- ✅ 微信消息接收与固定回复（"客服在开发中，敬请期待"）
- ✅ 大模型客户端接入（通义千问 + 字节豆包）
  - LLM Provider 统一接口
  - 通义千问客户端实现
  - 字节豆包客户端实现
  - 自动降级故障转移

## 待实现（按优先级）
1. **对话服务模块**
   - 消息预处理
   - 上下文构建
   - 调用 LLM 接口
   - 对话流程编排

2. **记忆服务模块**
   - 记忆抽取
   - 记忆存储
   - 记忆检索

3. **数据存储层**
   - PostgreSQL 用户和对话存储
   - Redis 会话缓存
   - 向量数据库连接

## 开发约束
- 遵循 TDD 模式：先写测试，再实现功能
- 任何代码修改前先出方案，确认后实施
- 复杂功能拆解为子任务逐步完成
- 测试使用 SQLite 替代 MySQL，miniredis 替代 Redis
