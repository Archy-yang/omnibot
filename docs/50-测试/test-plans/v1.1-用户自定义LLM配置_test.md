# 测试计划：V1.1 用户自定义 LLM 配置

---
## 测试用例：AES 加密工具

### 方法：TestAES_EncryptDecrypt

**测试目的**：验证 AES 加密后的数据可以正确解密还原

**输入参数**：
- 明文：`"sk-this-is-a-test-api-key-123456"`

**期望断言**：
- 加密结果不为空且不等于明文
- 解密结果等于原始明文
- 相同明文多次加密结果不同（有随机 nonce）

---
### 方法：TestAES_InvalidKey

**测试目的**：密钥错误时无法解密

**输入参数**：
- 用密钥 A 加密的数据
- 用密钥 B 解密

**期望断言**：
- 解密返回错误

---
## 测试用例：LLMConfig Repository

### 方法：TestLLMConfigRepository_CreateAndGet

**测试目的**：创建配置后可以正确查询

**输入参数**：
- user_id: 1
- api_key: 加密后的 `"sk-test-123"`
- base_url: `"https://custom.api.com/v1"`
- model: `"gpt-4"`

**期望断言**：
- Create 成功无错误
- GetByUserID 返回的配置与写入一致
- API Key 存储为密文

### 方法：TestLLMConfigRepository_Update

**期望断言**：

- updated_at 时间已更新

---
### 方法：TestLLMConfigRepository_Delete

**测试目的**：删除配置功能正常

**输入参数**：
- 创建配置后调用 Delete

**期望断言**：
- Delete 成功无错误
- 再次查询返回 gorm.ErrRecordNotFound

---
### 方法：TestLLMConfigRepository_UserUnique

**测试目的**：同一用户只能有一条配置

**输入参数**：

## 测试用例：LLMConfig Service

### 方法：TestLLMConfigService_SetAPIKey

**测试目的**：设置 API Key 后可以正确获取

**输入参数**：
- user_id: 1
- api_key: `"sk-abcdefghijklmnopqrstuvwxyz"`

**期望断言**：
- SetAPIKey 成功无错误
- GetConfigForUser 返回的 apiKey 与明文一致
- hasCustomConfig 为 true

---
### 方法：TestLLMConfigService_GetConfigView_Masked

**测试目的**：配置视图中 API Key 已脱敏

**输入参数**：
- 明文 Key: `"sk-abcdefghijklmnopqrstuvwxyz"`

**期望断言**：
- APIKeyMasked 格式为 `"sk-ab...yz"`
- 只显示前后各 3 个字符
- 中间用 `...` 替代

---
### 方法：TestLLMConfigService_GetConfigForUser_NoConfig

**测试目的**：用户无配置时返回正确状态

**输入参数**：
- 未创建过配置的 user_id

**期望断言**：
- hasCustomConfig 为 false
- apiKey, baseURL, model 为空字符串
- 无错误返回

---
### 方法：TestLLMConfigService_SetBaseURL_UseDefault

**测试目的**：未设置 BaseURL 时使用默认 OpenAI 地址

**输入参数**：
- 只设置 API Key，不设置 BaseURL

**期望断言**：
- GetConfigForUser 返回的 baseURL 为 `"https://api.openai.com/v1"`

---
### 方法：TestLLMConfigService_ClearConfig

**测试目的**：清除配置后恢复到系统默认

**输入参数**：
- 先创建用户配置

**期望断言**：

### 方法：TestLLMConfigService_InputValidation

**测试目的**：输入验证规则生效

## 测试用例：边界与异常

### 方法：TestLLMConfigService_RateLimit

**测试目的**：配置操作有流量限制保护

**输入参数**：
- 同一用户 1 分钟内连续调用 SetAPIKey 10 次

**期望断言**：
- 第 6 次及以后返回限流错误
- 只写入前 5 次的数据

---
### 方法：TestLLMCall_Timeout

**测试目的**：用户配置的地址超时时有友好提示

**输入参数**：
- 用户设置了无法访问的地址
- 发送对话消息

**期望断言**：
- 返回：`"❌ 模型服务访问失败，请检查 API 地址配置"`

---
### 方法：TestLLMCall_429RateLimit

**测试目的**：用户 Key 触发限流时有友好提示

**输入参数**：
- Mock LLM 返回 429 状态码

**期望断言**：
- 返回：`"❌ 调用次数已达上限，请稍后再试"`
