# v1.5 Agent 基本能力测试计划

---

## 测试目标

验证 OmniBot Web 端支持 Agent 基本能力：Tool Registry、OpenAI Function Calling 协议、ReAct 多步循环、内置工具调用，以及 Agent 执行过程通过 SSE 事件推送给前端。

---

## 测试范围

| 范围 | 覆盖 |
|------|------|
| Tool Registry | 工具注册、重名校验、查询、列表、OpenAI tools 格式转换 |
| Built-in Tools | `get_current_time`、`calculator`、`search_memories`、`search_history` |
| ReAct Agent | 无工具调用、单工具调用、工具失败、最大步数终止 |
| Web API | Agent 同步端点和 SSE 端点注册与调用 |
| Frontend | Agent SSE 事件解析、思考过程展示、构建通过 |

---

## 后端测试用例

### Tool Registry

- 注册新工具成功
- 重复注册同名工具返回错误
- 查询已注册工具成功
- 查询不存在工具返回 false
- `ToOpenAITools()` 输出符合 OpenAI Function Calling 的 `tools` 格式

### Built-in Tools

| 工具 | 用例 | 期望 |
|------|------|------|
| `get_current_time` | 无参数调用 | 返回非空当前时间字符串 |
| `calculator` | `2 + 3` | 返回 `5` |
| `calculator` | `(2+3)*4` | 返回 `20` |
| `calculator` | 非法字符 | 返回错误 |
| `search_memories` | 匹配关键词 | 返回匹配记忆 |
| `search_memories` | 无匹配 | 返回未找到提示 |
| `search_history` | v1.5 placeholder | 返回后续版本提示 |

### ReAct Agent

- 普通消息：LLM 无 `tool_calls`，直接返回最终文本
- 单工具调用：LLM 调用工具，Agent 执行工具并把结果回传，再返回最终文本
- 工具失败：工具错误作为 observation 回传，Agent 不崩溃
- 最大步数：达到限制后返回包含「已达到最大步数」的提示

## 前端验证用例

| 用例 | 期望 |
|------|------|
| Agent SSE 返回 `event: agent_step` | 前端解析并写入当前助手消息的 `agentSteps` |
| Agent 返回最终 content | 助手消息正文正常展示 |
| 消息包含 Agent steps | ChatMessage 显示「查看思考过程」折叠区 |
| 普通消息无 steps | 不显示思考过程折叠区 |

## 手工 Smoke 验证

1. 启动后端：`go run cmd/server/main.go -config configs/config.yaml`
2. 启动前端：`npm --prefix frontend run dev -- --host 127.0.0.1`
3. 访问 `http://127.0.0.1:5173/`
4. 发送「现在几点了？」：期望 Agent 调用 `get_current_time`
5. 发送「帮我算一下 (123 + 456) * 7」：期望 Agent 调用 `calculator`
6. 发送「你好」：期望不调用工具，正常回复
