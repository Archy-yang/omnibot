# v1.4.1 OpenAI 兼容服务商预设配置测试计划

---

## 测试目标

验证 Web 用户级 LLM 配置支持 OpenAI-compatible 服务商预设：OpenAI 官方、百度千帆、字节火山、阿里千问、自定义 OpenAI-compatible；验证专用 Provider 展示但不可保存；验证保存后同步聊天和 SSE 流式聊天走用户 OpenAI-compatible 配置。

---

## 测试范围

| 范围 | 覆盖 |
|------|------|
| 后端服务层 | 验证 provider 预设列表、provider 校验、默认 Base URL / 模型、编辑时保留旧 API Key |
| LLM 客户端工厂 | 验证新 preset ID 走 OpenAIProvider；legacy qwen/doubao 保留专用 Provider |
| Web API | 验证 provider-options API、配置保存 API、禁用专用 Provider 错误 |
| 前端设置面板 | 验证分组展示、禁用状态、预设自动填充、保存 payload |
| 运行验证 | 验证后端 API smoke、前端页面可访问、配置保存后聊天调用路径 |

## 后端测试用例

### TestListProviderOptions

- **Setup**: 调用 `service.ListProviderOptions()`
- **Assert**: 返回列表包含 `openai`, `baidu_qianfan`, `volcengine`, `aliyun_qwen`, `custom_openai_compatible` 可用项；包含 `qianfan_native`, `qwen_native`, `doubao_native` 禁用项（`disabled: true`）。

### TestPresetDefaults_BaiduQianfan

- **Setup**: 通过 `SaveConfig` 保存 `baidu_qianfan` 预设，不传 `BaseURL` 和 `Model`
- **Assert**: 默认 Base URL 为 `https://qianfan.baidubce.com/v2`，默认模型为 `ernie-4.0-turbo-8k`。

### TestPresetDefaults_Volcengine

- **Setup**: 通过 `SaveConfig` 保存 `volcengine` 预设，不传 `BaseURL` 和 `Model`
- **Assert**: 默认 Base URL 为 `https://ark.cn-beijing.volces.com/api/v3`，默认模型为 `doubao-seed-1-6`。

### TestPresetDefaults_AliyunQwen

- **Setup**: 通过 `SaveConfig` 保存 `aliyun_qwen` 预设，不传 `BaseURL` 和 `Model`
- **Assert**: 默认 Base URL 为 `https://dashscope.aliyuncs.com/compatible-mode/v1`，默认模型为 `qwen-plus`。

### TestPreset_CustomMissingBaseURL

- **Setup**: 通过 `SaveConfig` 保存 `custom_openai_compatible` 预设，`BaseURL` 为空
- **Assert**: 返回验证错误 `"请输入 API 地址"`。

### TestPreset_DisabledNativeProvider

- **Setup**: 通过 `SaveConfig` 保存 `qwen_native`, `doubao_native` 或 `qianfan_native` 之一
- **Assert**: 返回验证错误 `"专用接口暂不可用，请使用 OpenAI 兼容模式"`。

### TestPreset_EditPreservesEmptyAPIKey

- **Setup**: 已存在一条含 API Key 的配置；调用 `SaveConfig` 编辑该配置，`APIKey` 传空字符串，其他字段传新值
- **Assert**: 存储后 API Key 保持旧值，仅其他字段被更新。

### TestFactory_RoutesNewPresetsToOpenAIProvider

- **Setup**: 调用 `NewClientFromUserConfig`，`Provider` 为 `baidu_qianfan` / `volcengine` / `aliyun_qwen`
- **Assert**: 返回 `*OpenAIProvider` 类型的客户端。

### TestFactory_RoutesLegacyToNativeProvider

- **Setup**: 调用 `NewClientFromUserConfig`，`Provider` 为 `qwen` / `doubao`
- **Assert**: 返回对应专用 Provider 类型的客户端（如 `*QwenProvider` / `*DoubaoProvider`）。

## 前端验证用例

| 用例 | 期望 |
|------|------|
| 打开设置面板 | 先加载 provider options，再展示 LLM 配置表单 |

## 手工 Smoke 验证

1. 启动后端：`go run cmd/server/main.go -config configs/config.yaml`
2. 启动前端：`npm --prefix frontend run dev -- --host 127.0.0.1`
3. 访问 `http://127.0.0.1:5173/`
4. 打开设置面板，选择 OpenAI 兼容预设，保存配置。
5. 调用 `GET /api/v1/user/llm-config?session_id=<session>`，确认 `provider`、`base_url`、`model` 已保存。
