# 50-测试

本目录存放测试计划、测试用例、测试报告，遵循 TDD 开发流程。

## 目录结构

```
50-测试/
├── test-plans/            # 测试计划文档
│   └── internal/         # 按代码目录结构镜像
│       ├── api/
│       ├── db/
│       ├── service/
│       └── ...
└── test-reports/         # 测试覆盖率报告、集成测试报告
```

## 测试计划格式要求

每个测试方法独立成 section，包含：

```markdown
## 方法：TestName

**测试目的**：...

**输入参数**：
- ...

**期望断言**：
- ...
```

## 测试原则

1. **TDD 流程**：先写测试计划 → 写测试代码 → 实现功能 → 验证通过
2. **接口级系统测试**：不 mock 处理器，启动真实路由，走完整调用链
3. **数据库测试**：使用 SQLite 内存数据库，无需外部依赖
4. **Redis 测试**：使用 miniredis 替代真实 Redis
5. **文档与代码同步**：测试代码与测试计划文档一一对应
