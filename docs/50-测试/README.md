# 50-测试

本目录存放测试计划、测试用例、测试报告，遵循 TDD 开发流程。

## 目录结构

```
50-测试/
├── test-plans/            # 历史测试计划(v1.1~v2.x 时代的发布前 smoke 与单测计划,均已执行或失效)
│   └── internal/         # 早期按代码目录镜像的单测计划(与代码现状可能不符,仅留档)
└── test-reports/         # 测试报告(如 v2.x-smoke-report)
```

> 注：日常开发的 TDD 测试直接落在 Go 代码中（`go test ./...`），本目录仅承载
> 发布前 smoke 类的计划与报告；新测试计划按需新增。

## 测试计划格式要求

每个测试方法独立成 section，包含：

```markdown
## 方法：TestName

**测试目的**：...

**输入参数**：
- ...

**期望断言**：
- ...
```

## 测试原则

1. **TDD 流程**：先写测试计划 → 写测试代码 → 实现功能 → 验证通过
2. **接口级系统测试**：不 mock 处理器，启动真实路由，走完整调用链
3. **数据库测试**：使用 SQLite 内存数据库，无需外部依赖
4. **Redis 测试**：使用 miniredis 替代真实 Redis
5. **文档与代码同步**：测试代码与测试计划文档一一对应
