# 开源参考设计

## 概述

本文档收集优秀的开源 AI 聊天界面设计，作为 OmniBot 前端重构的参考。

## Chatbot UI

### 项目信息
- **地址**: https://github.com/mckaywrigley/chatbot-ui
- **技术栈**: Next.js + TypeScript + Tailwind CSS
- **特点**: 功能完整的开源 ChatGPT 界面

### 设计亮点

#### 1. 布局结构
```
┌─────────────────────────────────────────────────────────┐
│  [Logo]  New Chat          [User Menu]                  │
├──────────────┬──────────────────────────────────────────┤
│  Chat 1      │                                          │
│  Chat 2      │          Message List                    │
│  Chat 3      │                                          │
│  Chat 4      │                                          │
│              │                                          │
│              │                                          │
│              ├──────────────────────────────────────────┤
│              │  [Input Box]                  [Send]     │
└──────────────┴──────────────────────────────────────────┘
```

#### 2. 可借鉴点
- 左侧会话列表 + 右侧聊天区域的经典布局
- 会话项 hover 显示操作按钮（重命名、删除）
- 输入框支持 Shift + Enter 换行
- 代码块一键复制功能
- 消息气泡两侧对齐（用户右、助手左）

## LibreChat

### 项目信息
- **地址**: https://github.com/danny-avila/LibreChat
- **技术栈**: React + TypeScript + Tailwind CSS
- **特点**: 多模型支持、功能丰富

### 设计亮点

#### 1. 消息操作栏
```
┌─────────────────────────────────────────┐
│  Assistant message content here...      │
│  Code block with syntax highlighting    │
├─────────────────────────────────────────┤
│  Copy | Edit | Regenerate | Good Answer │
└─────────────────────────────────────────┘
```

#### 2. 可借鉴点
- 每条消息底部有操作栏（hover 显示）
- 支持消息编辑和重新生成
- 回复的点赞/点踩反馈
- 详细的消息时间戳
- 流式响应打字机效果

## ChatGPT Web UI (Official)

### 设计亮点

#### 1. 极简主义设计
- 大面积留白，内容聚焦
- 低饱和度配色，减少视觉疲劳
- 阴影使用克制，只有卡片轻微阴影

#### 2. 消息气泡设计
```
┌─────────────────────────────────────────────────────┐
│                                                     │
│   User message (right-aligned, dark background)    │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│ 🤖                                                  │
│ Assistant message (left-aligned, no background)     │
│                                                     │
│ Code block with dark theme:                         │
│ ┌───────────────────────────────────────────────┐   │
│ │ const hello = "world";                        │   │
│ │ Copy                                           │   │
│ └───────────────────────────────────────────────┘   │
│                                                     │
│ Regenerate response                                 │
└─────────────────────────────────────────────────────┘
```

#### 3. 可借鉴点
- 助手消息不使用气泡，直接在白底上显示
- 用户消息使用深色背景气泡右对齐
- 代码块独立设计，深色主题，带复制按钮
- 消息底部的"重新生成"按钮
- 输入框自动高度（随内容增多而变高）

## 设计方向总结

### OmniBot 设计定位

**风格关键词：** 简洁、现代、专业、高可读性

### 核心设计决策

#### 1. 布局
```
┌─────────────────────────────────────────────────────┐
│  OmniBot Logo                          [Settings]  │
├─────────────────────────────────────────────────────┤
│                                                     │
│              Message List (Full Width)              │
│                                                     │
│  ┌─────────────────────────────────────────────┐   │
│  │ User message (right)                        │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  🤖 Assistant message (left, no bubble)             │
│                                                     │
│  ┌─────────────────────────────────────────────┐   │
│  │ Code block - dark theme                    │   │
│  │ Copy                                        │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
├─────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────┐        │
│  │ Message Input (auto-height)          [Send]       │
│  └─────────────────────────────────────────┘        │
│  💡 Tip: Use "#设置" to configure your LLM           │
└─────────────────────────────────────────────────────┘
```

#### 2. 配色方案
- **主色**: 紫色/靛蓝色系 (`#6366f1`) - 代表智能、科技
- **背景**: 极浅灰 (`#f9fafb`) - 柔和不刺眼
- **内容区**: 纯白 - 保证阅读舒适度

#### 3. 排版
- **正文**: 16px, 行高 1.6 - 保证长文本阅读体验
- **代码**: 14px, 等宽字体 - 代码块深色主题

### 动效原则
- **克制**: 只有必要的动画（消息进入、加载状态）
- **快速**: 动画时长 150-200ms，不拖沓
- **自然**: 缓动函数使用 ease-out，感觉更自然

## 开源组件库参考

### Markdown 渲染
- **react-markdown** - React 生态最成熟
- **markdown-it** - 可定制性强，Vue 可直接使用
- **@iktakahiro/markdown-it-katex** - 数学公式支持

### 代码高亮
- **highlight.js** - 功能完整，主题多
- **prism.js** - 轻量，主题更现代

### 虚拟滚动
- **vue-virtual-scroller** - Vue 生态最成熟
- **vue-virtual-scroll-list** - 轻量选项
