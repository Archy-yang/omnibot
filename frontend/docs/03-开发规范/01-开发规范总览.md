## TypeScript 规范

### 类型定义

✅ **推荐写法：**
```typescript
// 使用 interface 定义对象类型
interface User {
  id: number;
  name: string;
  avatar?: string;
}

// 使用 type 定义联合类型和函数类型
type MessageRole = 'user' | 'assistant' | 'system';
type SendMessage = (content: string) => Promise<void>;

// 泛型约束
interface ApiResponse<T = unknown> {
  success: boolean;
  data: T;
}
```

❌ **禁止写法：**
```typescript
// 禁止使用 any
const data: any = await fetch();

// 禁止类型断言成 any
const result = obj as any;

// 禁止隐式 any
function process(value) { /* ... */ }
```

### 类型推断

- 优先利用 TypeScript 的类型推断能力
- 只有推断不出来或需要明确类型时才手动标注

```typescript
// ✅ 可以省略，能自动推断
const name = 'OmniBot';
const list = ref<string[]>([]);

// ❌ 没必要的类型标注
const name: string = 'OmniBot';

// ✅ 需要明确标注的情况
const userStore = useUserStore(); // 类型由 store 定义
```

## Vue 3 规范

### Composition API 写法

✅ **推荐写法：**
```vue
<script setup lang="ts">
import { ref, computed, onMounted } from 'vue';

// 1. Props 定义
const props = defineProps<{
  messages: Message[];
  loading?: boolean;
}>();

// 2. Emits 定义
const emit = defineEmits<{
  (e: 'send', content: string): void;
  (e: 'retry', messageId: string): void;
}>();

// 3. 响应式数据
const inputValue = ref('');
const isSending = ref(false);

// 4. 计算属性
const canSend = computed(() => !!inputValue.value.trim() && !isSending.value);

// 5. 方法
const handleSend = async () => {
  if (!canSend.value) return;
  emit('send', inputValue.value);
  inputValue.value = '';
};

// 6. 生命周期
onMounted(() => {
  // ...
});
</script>
```

### Script Setup 顺序

严格按照以下顺序组织代码：

1. **import 导入** → 第三方库放在前面，内部模块放在后面
2. **defineProps / defineEmits**
3. **响应式数据** (ref, reactive, computed)
4. **方法定义**
5. **生命周期钩子**
6. **watch / watchEffect**
7. **defineExpose** (如果需要)

### Props 定义

✅ **推荐写法：**
```typescript
// 有默认值的情况
const props = withDefaults(defineProps<{
  messages: Message[];
  loading?: boolean;
  placeholder?: string;
}>(), {
  loading: false,
  placeholder: '输入消息...'
});

// 必填 props 不需要默认值
interface Props {
  messages: Message[]; // 必填
}
```

## 命名规范

### 文件命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 组件 | PascalCase | `ChatMessage.vue`, `UserAvatar.vue` |
| Composable | camelCase，use 开头 | `useChat.ts`, `useSession.ts` |
| Store | camelCase | `chatStore.ts`, `userStore.ts` |
| Service | camelCase | `chatService.ts`, `userService.ts` |
| 类型定义 | camelCase，类型后缀 | `chatTypes.ts`, `apiTypes.ts` |
| 工具函数 | camelCase | `storage.ts`, `format.ts` |
| 页面 | PascalCase | `ChatPage.vue`, `SettingsPage.vue` |

### 变量命名

| 类型 | 规范 | 示例 |
|------|------|------|
| 普通变量 | camelCase | `messageList`, `isLoading` |
| 常量 | UPPER_SNAKE_CASE | `MAX_MESSAGE_LENGTH`, `SESSION_KEY` |
| 布尔值 | is/has/can 开头 | `isSending`, `hasMore`, `canRetry` |
| 函数 | 动词开头 | `sendMessage`, `loadHistory`, `formatTime` |
| ref 变量 | 普通命名即可 | `const input = ref('')` |

### 组件命名

- 组件名使用 PascalCase
- 业务组件使用前缀标识所属模块：`ChatMessage`, `ChatInput`
- 基础组件使用 `Base` 前缀：`BaseButton`, `BaseInput`

## 代码风格规范

### 导入顺序

```typescript
// 1. Vue 核心
import { ref, computed } from 'vue';

// 2. 第三方库
import { useRouter } from 'vue-router';
import { NButton } from 'naive-ui';

// 3. 内部模块
import { useChat } from '@/composables/useChat';
import { useUserStore } from '@/stores/user';
import { chatService } from '@/services/chat';

// 4. 类型导入
import type { Message } from '@/types/chat';

// 5. 静态资源
import Logo from '@/assets/icons/logo.svg';
```

### 函数编写

```typescript
// ✅ 推荐：使用箭头函数，适当注释
const sendMessage = async (content: string): Promise<void> => {
  if (!content.trim()) return;
  
  try {
    isSending.value = true;
    await chatService.send(content);
  } catch (error) {
    console.error('发送失败:', error);
  } finally {
    isSending.value = false;
  }
};

// ✅ 推荐：单一职责
const formatTime = (timestamp: number): string => {
  return new Date(timestamp).toLocaleString('zh-CN');
};
```

### 注释规范

- **业务逻辑复杂处**必须加注释
- **公共组件/函数**必须有 JSDoc 注释

```typescript
/**
 * 发送聊天消息
 * @param content - 消息内容
 * @param options - 发送选项
 * @returns Promise<void>
 * @example
 * await sendMessage('你好', { silent: false });
 */
const sendMessage = async (
  content: string,
  options?: { silent?: boolean }
): Promise<void> => {
  // ...
};
```

## Tailwind CSS 使用规范

### 原子类顺序

按照「布局 → 盒模型 → 排版 → 外观」的顺序书写类名：

```html
<!-- ✅ 推荐：有逻辑的顺序 -->
<div class="
  flex items-center justify-center  <!-- 布局 -->
  w-64 h-32 p-4 mx-2                <!-- 盒模型 -->
  text-lg font-medium text-gray-700 <!-- 排版 -->
  bg-white rounded-lg shadow        <!-- 外观 -->
">
```

### 自定义样式

- 通用样式提取为 Tailwind 插件
- 特殊情况使用 `@apply` 或 `style` 标签
- 禁止滥用 `!important`

```vue
<!-- ✅ 推荐：少量自定义样式用 scoped -->
<style scoped>
.message-enter-active {
  transition: all 0.3s ease-out;
}
</style>
```

## Git 提交规范

### Commit Message 格式

```
<type>(<scope>): <subject>

<body>

<footer>
```

### Type 类型

| 类型 | 说明 |
|------|------|
| `feat` | 新功能 |
| `fix` | 修复 bug |
| `docs` | 文档更新 |
| `style` | 代码格式（不影响代码运行） |
| `refactor` | 重构（既不是新增功能，也不是修改 bug） |
| `perf` | 性能优化 |
| `test` | 测试相关 |
| `chore` | 构建过程或辅助工具的变动 |
| `revert` | 回滚 |

### Scope（可选）

影响的模块：`chat`, `settings`, `router`, `build` 等

### Subject

- 简短描述，不超过 50 字符
- 使用动词开头：add, remove, update, fix, refactor 等
- 中文或英文均可，保持一致

### 示例

```
feat(chat): 支持消息复制功能

- 添加复制按钮
- 支持代码块一键复制

Closes #123
```

## 开发流程规范

### 分支管理

- `master`：主分支，生产环境代码
- `develop`：开发分支
- `feature/xxx`：功能分支
- `bugfix/xxx`：bug 修复分支

### 开发流程

1. 从 `develop` 创建 `feature/xxx` 分支
2. 开发完成，自测通过
3. 提交 PR，代码审查
4. 合并到 `develop` 分支
5. 测试环境验证
6. 合并到 `master` 发布
