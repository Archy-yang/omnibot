# 样式规范

## 概述

本文档定义 OmniBot 前端样式规范，包括设计系统、颜色体系、排版、间距、响应式设计等。

---

## 设计系统

### 设计参考

参考以下开源项目设计风格：
- **DeepSeek Harness (dsh)**：**当前实际采用**。设计令牌移植自其 `ui-theme`（design-platform.css），白底近黑文字、浅蓝气泡、0.5px 细线分隔、胶囊按钮
- **ChatGPT**：清晰、简洁、功能优先（v2.2 前的旧基线，已替换）
- **Notion AI**：简洁、现代、以内容为中心
- **Claude**：专业、稳重、高可读性

> **令牌实现**：全部颜色/字体/圆角以 CSS 变量定义在 `src/style.css`（亮色 `:root`，暗色 `:root.dark`，由 App.vue 的 `html.dark` 切换）。组件内**禁止写死色值**，一律引用 `var(--xxx)` 令牌。

## 颜色体系

### 主色调 (Primary / Accent)

取自 dsh 的 deepseek 蓝阶。注意：dsh 体系里**主按钮是黑底白字**，蓝色只用于链接、聚焦、信息动作。

| 令牌 | 色值 | 用途 |
|--------|--------|------|
| `--ds-blue-50` | `#edf3fe` | 用户气泡底、极浅蓝背景 |
| `--ds-blue-100` | `#e4edfd` | 侧栏选中强调 |
| `--ds-blue-200` | `#d3e2ff` | 高亮 |
| `--ds-blue-400` | `#679efe` | 暗色模式主蓝 |
| **`--ds-blue-500`** | `#4176e6` | **主蓝：链接、聚焦边、品牌标识** |
| `--accent` | = blue-500（暗色=blue-400） | 组件内引用的别名 |

### 中性色 (Neutral-bluish)

取自 dsh 的 bluish 灰阶（微蓝调灰）。

| 令牌 | 色值 | 用途 |
|--------|--------|------|
| `--ds-gray-00` | `#ffffff` | 基础底色 |
| `--ds-gray-50` | `#f9fafb` | 侧栏底、代码块底 |
| `--ds-gray-75` | `#f1f3f5` | 悬浮底 |
| `--ds-gray-100` | `#ebeef2` | 选中底 |
| `--ds-gray-200` | `#e1e5ee` | 滚动条、暗色边框基准 |
| `--ds-gray-400` | `#adb2b8` | 占位符、弱图标（caption） |
| `--ds-gray-600` | `#81858c` | 三级文字 |
| `--ds-gray-700` | `#61666b` | 二级文字 |
| `--ds-gray-750` | `#43454a` | 主按钮 hover（亮色） |
| `--ds-gray-850` | `#2c2c2e` | 暗色气泡/输入底 |
| `--ds-gray-950` | `#151517` | 暗色页面底 |
| `--ds-gray-1000` | `#0f1115` | 主文字、亮色主按钮底 |

### 语义色 (Semantic)

| 令牌 | 亮色 | 用途 |

### 语义色 (Semantic)

| 类型 | 色值 | 用途 |

| Success | `#10b981` | 成功状态、正确答案 |

### Tailwind 配置

令牌不进 tailwind.config，统一走 CSS 变量（`src/style.css`）。Tailwind 类里需要引用时用任意值语法，如 `bg-[var(--accent)]`。

## 间距体系

使用 4px 基础间距系统：

| 间距名 | 数值 | 用途 |
|---------|------|------|
| xs | 4px | 极小间距、图标内边距 |
| sm | 8px | 小组件内边距、紧凑布局 |
| md | 12px | 组件内边距 |
| base | 16px | 标准内边距、卡片间距 |
| lg | 24px | 大组件内边距、区块间距 |
| xl | 32px | 页面区块间距 |
| 2xl | 48px | 大区块间距 |
| 3xl | 64px | 页面边距 |

### 间距使用原则

- **水平间距**：按钮间距 8px，表单控件间距 16px
- **垂直间距**：段落间距 16px，区块间距 24px
- **内边距**：卡片内边距 16-24px，按钮内边距 8px 16px

## 圆角体系

dsh 特征：所有圆角面在支持的引擎上以 `corner-shape: superellipse(1.5)` 超椭圆渲染（`style.css` 全局注入，渐进增强，不支持的引擎自动回退普通圆角）。

| 圆角名 | 数值 | 用途 |
|---------|------|------|
| sm | 4px | 徽标 |
| md | 8px | 输入框、图标按钮、导航项 |
| lg | 12-14px | 卡片、Toast |
| xl | 16px | 输入区容器、工具结果块 |
| bubble | 22px | 用户消息气泡 |
| capsule | 高度一半（如 36px 高 → 18px） | 主/幽灵/outline 按钮（dsh 胶囊形） |
| full | 9999px | 圆形头像、圆形图标按钮 |

## 组件样式规范

### 按钮样式（dsh 胶囊形，h36 r18 / sm h28 r14）

| 类型 | 样式 |
|------|------|
| Primary | `bg: var(--btn-primary-fill)`（近黑）+ `color: var(--btn-primary-foreground)`；hover `var(--btn-primary-hover)` |
| Accent | `bg: var(--accent)` + 白字（信息/品牌动作用） |
| Outline | `0.5px solid var(--border-l3)` 透明底；hover `var(--bg-hover)` |
| Ghost | 透明底；hover `var(--bg-hover)`，active `var(--bg-active)` |

### 输入框样式

```css
.input-base {
  @apply px-4 py-2.5 border border-gray-200 rounded-lg;
  @apply text-gray-700 bg-white;
  @apply focus:outline-none focus:ring-2 focus:ring-primary-500/20 focus:border-primary-500;
  @apply transition-all duration-200;
}
```

### 消息气泡样式（dsh：右对齐浅蓝气泡，助手无底色）

```css
/* 用户消息：右对齐，极浅蓝底 */
.message-user {
  background: var(--bubble-user);   /* 亮 #edf3fe / 暗 #2c2c2e */
  color: var(--label-primary);
  border-radius: 22px;
  padding: 10px 16px;
  font-size: 14px;
}

/* 助手消息：无底色纯文本，左侧头像列 */
.message-assistant {
  color: var(--label-primary);
  font-size: 14px;
}
```

## 动画规范

### 过渡时长

| 时长 | 用途 |
|------|------|
| 150ms | 颜色、阴影变化 |
| 200ms | 位移、缩放、普通过渡 |
| 300ms | 页面切换、弹窗动画 |

### 缓动函数

```css
transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1);
```

### 常用动画

```css
/* 淡入 */
.fade-enter-active {
  transition: opacity 0.2s ease;
}
.fade-enter-from {
  opacity: 0;
}

/* 滑入 */
.slide-up-enter-active {
  transition: all 0.3s ease;
}
.slide-up-enter-from {
  opacity: 0;
  transform: translateY(10px);
}
```

## 暗色模式 (Dark Mode)

### 暗色模式配色原则

1. 纯黑背景避免使用 `#000000`，使用 `#0f172a` 或 `#111827`
2. 文字对比度适中，避免纯白 `#ffffff`，使用 `#f9fafb`
3. 边框使用半透明白色或深灰色

### 暗色模式颜色映射

| 亮色 | 暗色 | 说明 |
|------|------|------|
| bg-white | bg-gray-900 | 卡片背景 |
| bg-gray-50 | bg-gray-800 | 页面背景 |
| border-gray-200 | border-gray-700 | 边框 |
| text-gray-700 | text-gray-200 | 正文 |
| text-gray-500 | text-gray-400 | 次要文字 |

### 实现方式

使用 Tailwind 的 `dark:` 变体 + CSS 变量：

```html
<!-- 支持深色模式 -->
<div class="bg-white dark:bg-gray-900 text-gray-700 dark:text-gray-200">
  内容
</div>
```
