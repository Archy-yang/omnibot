## 设计原则

### 核心原则
1. **用户体验优先** - 简洁、快速、易用
2. **类型安全** - 全程 TypeScript，避免运行时错误
3. **性能优先** - 虚拟滚动、懒加载、合理缓存
4. **可维护性** - 清晰的架构、统一的规范
5. **渐进式迭代** - 小步快跑，每个阶段都可交付

### 不要做的事情
❌ 不要为了技术而技术  
❌ 不要过度设计，保持简单  
❌ 不要过早优化，先跑起来再优化  
❌ 不要引入过多依赖，保持轻量

## 给 AI 助手的特别说明

Claude / GPT 等 AI 助手在进行前端开发时：

1. **每次对话开始**，必须确认已经阅读了 `frontend/docs/` 下的相关文档
2. **写任何代码前**，必须先阅读对应领域的规范文档
3. **拿不准时**，先问，不要猜，不要"先实现了再说"
4. **严格遵循** [00-前端开发宪章.md](./01-宪章/00-前端开发宪章.md) 的所有约束
