## v2.0 详细开发计划

**目标：** 完成项目脚手架搭建和基础配置

- [ ] 创建 Vue 3 + Vite + TypeScript 项目
- [ ] 配置 Tailwind CSS
- [ ] 配置 Naive UI
- [ ] 配置 Pinia + Vue Router
- [ ] 配置 ESLint + Prettier

## 风险与应对

| 风险 | 影响 | 概率 | 应对措施 |
|------|------|------|----------|
| Markdown 渲染性能问题 | 高 | 中 | 提前调研库选型（markdown-it vs marked），考虑虚拟滚动 |
| 移动端体验不佳 | 中 | 中 | 严格按照 mobile-first 开发，真机测试 |
| Go Embed 集成问题 | 高 | 低 | 提前验证构建产物路径，保留回滚方案 |
| 开发时间不足 | 高 | 中 | 优先保证核心功能，高级功能延后到后续版本 |
